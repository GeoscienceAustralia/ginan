> **16 Sep 2026** - the Ginan team is pleased to release Ginan patch v4.1.4
>
> **Highlights**:
>
> * Added a PPP option to estimate troposphere residuals with a Gauss-Markov process
> * Fixed SouthPAN L1 and DFMC carrier smoothing, including correct time-based smoothing windows and outage validation
> * Fixed DFMC GPS IODE decoding and L1 slow-correction validity handling
> * Fixed PVS-on-DFMC clock-correction variance and SBAS receiver-variance calculation
> * Improved diagnostics for rejected pseudoranges and unavailable SBAS corrections, and skip RAIM when too few valid measurements remain
> * The binaries can be found on the GitHub website:
>   * [Ginan v4.1.4 Binaries](https://github.com/GeoscienceAustralia/ginan/releases/tag/v4.1.4)
