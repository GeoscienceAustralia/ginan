## 2. 数学实现边界

### 2.1 弧段退出后的精确幸存格

旧约束写成：

`H_S k_S + H_R k_R = z`。

实现计算 `H_R^T` 的饱和整数核 `K_R`，然后构造：

`H' = K_R^T H_S`，`z' = K_R^T z`，

最后对 `(H', z')` 同步执行精确行 HNF。全过程使用任意精度整数，不使用浮点秩、浮点逆或事后舍入。

独立真值案例中，三行旧约束全部触碰退出弧段：旧策略秩为 0；整数左核为 `[1,-1,0]`；精确策略保留 `[1,-1] = -2`，秩为 1。C++ 与 SymPy 结果一致。

### 2.2 产品树交换的不变量

文档中若将树交换验证写成 `G_old k_old = G_new k_new`，该等式一般不成立。正确不变量是：

`z_T,old + G_old k_old = z_T,new + G_new k_new = z_P`。

因为动态树改变时，树节点整数势 `z_T` 本身也改变。3x3 小图测试按这个完整不变量验证通过。
